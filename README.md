# Autonomous Navigation Under Partial Observability

## Problem

An autonomous agent must navigate toward a goal in an environment that will eventually contain obstacles, incomplete observations, and uncertainty.

## Current Scope

Day 1 focuses on building the minimal interaction between an agent and its environment.

The agent currently has:
- A 2D position
- Four possible actions: UP, DOWN, LEFT, RIGHT

The environment currently has:
- A 2D grid
- A fixed goal
- A simple visualization

## Current System

Current State → Action → Environment → Next State
